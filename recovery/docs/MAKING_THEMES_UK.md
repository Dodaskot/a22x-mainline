# Як зробити власну тему

Mainline Recovery може брати теми й кольори термінала з файла. Тема — це невеликий текстовий файл
із закінченням `.a22xtheme`. Його можна написати в будь-якому текстовому редакторі; інструменти
потрібні лише для фонового малюнка.

English: [MAKING_THEMES.md](MAKING_THEMES.md) · Кожне поле докладно: [THEMES_API.md](../THEMES_API.md)

## 1. Тема з вашими кольорами

Збережіть це як `deep-sea.a22xtheme`:

```json
{
  "format": 1,
  "code": "deep-sea",
  "name": "Deep Sea",
  "note": "Dark blue with a coral accent",
  "dark": true,
  "layout": "tiles",
  "colors": {
    "bg": "#0b1622",
    "panel": "#13263a",
    "text": "#eaf3fb",
    "muted": "#9fb6c9",
    "accent": "#ff7f6a",
    "on_accent": "#2a0d07"
  }
}
```

Обов'язкових кольорів шість:

| Колір | Де він видний |
|---|---|
| `bg` | Тло сторінки |
| `panel` | Картки й кнопки |
| `text` | Звичайний текст |
| `muted` | Дрібніші підписи під текстом |
| `accent` | Головні кнопки, вибраний варіант, перемикачі |
| `on_accent` | Текст на кольорі `accent` |

Решту (рамки, велику картку «Встановлення», кольори плиток) recovery виводить із цих шести. Кожен
з них можна задати й самому; назви є в [THEMES_API.md](../THEMES_API.md).

Інші поля:

- `code`: коротка назва, від 3 до 23 символів `a-z`, `0-9` і `-`. Назви вбудованих тем
  (`graphite`, `daylight`, `aurora`…) не дозволені.
- `name` і `note`: що показує список тем.
- `dark`: `true` для темної теми, `false` для світлої.
- `layout`: `tiles` для великої головної сторінки з плитками, `list` для простого списку.

## 2. Кольори термінала

Файл лише з розділом `terminal` додає кольори термінала без теми. Палітра має 16 кольорів: чорний,
червоний, зелений, жовтий, синій, пурпуровий, блакитний, білий, а потім ці ж вісім у яскравому
варіанті.

```json
{
  "format": 1,
  "code": "my-terminal",
  "name": "My terminal",
  "terminal": {
    "background": "#101418",
    "foreground": "#d8dee9",
    "palette": ["#101418", "#e06c75", "#98c379", "#e5c07b", "#61afef", "#c678dd", "#56b6c2", "#abb2bf",
                "#5c6370", "#ff7b86", "#b5e08f", "#ffd68a", "#82c4ff", "#dd9cf0", "#7fd3dd", "#ffffff"]
  }
}
```

Тема теж може мати розділ `terminal`; тоді обидва беруться з одного файла.

## 3. Як поставити її на телефон

1. Скопіюйте файл на microSD, USB-накопичувач або сам телефон (наприклад, через «USB-файли» в
   recovery).
2. У recovery відкрийте **Налаштування → Тема → Додати тему з файлу** (або **Налаштування → Кольори
   термінала → Додати кольори з файлу**) і виберіть файл. Можна також торкнутися файла у
   **Файлах** і натиснути **Застосувати тему**.

Тема лишається після перезапуску. Можна додати до восьми тем. Щоб прибрати тему, двічі торкніться
кошика на її картці.

## 4. Перевірка читабельності

Перш ніж прийняти тему, recovery перевіряє контраст тексту з тлом. Тему, яку важко читати, він
відкидає з повідомленням **THEME_UNREADABLE**, тож ви ніколи не опинитеся перед екраном, який
неможливо прочитати. Якщо так сталося, зробіть `text` і `muted` світлішими на темній темі (або
темнішими на світлій) і спробуйте ще раз.

## 5. Фоновий малюнок

Для малюнка під картками потрібен комп'ютер із Python і Pillow:

```
tools/pack_theme.py deep-sea.json --image picture.png --output deep-sea.a22xtheme
```

`deep-sea.json` — той самий текст, що вище. Малюнок масштабується до 540 × 1204. Необов'язкове
поле `glass` задає, наскільки він просвічує крізь картки:

```json
"glass": {"surface_alpha": 176, "edge_alpha": 84, "shadow_strength": 84}
```

`themes/beaver.json` — повний приклад з малюнком, а `themes/draw_beaver.py` його малює.
